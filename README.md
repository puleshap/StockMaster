# Real-Time Stock Management ERP

A standalone Enterprise Resource Planning (ERP) desktop application built entirely in Java, designed to help businesses manage stock and inventory in real-time through a native GUI.

## Overview

This ERP system focuses on the core inventory challenge businesses face: knowing exactly what stock they have, where it is, and when it changes — as it happens. Built as a pure Java desktop application (no external web server required), it gives businesses a lightweight, self-contained tool for real-time stock control.

## Key Features

- **Real-Time Stock Tracking**
  Stock levels update immediately as items are added, sold, or moved, giving an accurate live view of inventory.

- **Desktop GUI**
  Native Java GUI application — runs locally without needing a browser or web server.

- **Inventory Management**
  Add, update, and remove stock items, with tracking of quantities and item details.

- **Business-Oriented ERP Workflows**
  Structured around common ERP needs such as stock intake, stock movement, and reporting.
